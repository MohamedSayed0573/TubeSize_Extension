# TubeSize Domain Glossary

Canonical domain vocabulary for **TubeSize**, a Manifest V3 browser extension with two bounded contexts:

1. **Usage Tracking (Post-hoc / Measured)** — Counting actual network bytes transferred across all websites and attributing traffic on supported platforms to watched media.
2. **Size Estimation (Pre-play / Predicted)** — Resolving media manifests to estimate total download size and/or data rate per quality tier before or during playback.

All size and rate calculations use **decimal SI units (base 1000)**: `1 KB = 1,000 B`, `1 MB = 1,000,000 B`, `1 GB = 1,000,000,000 B` (matching ISP data caps; see [`src/lib/format.ts`](src/lib/format.ts)).

## 1. Platforms & Media Identity

| Term                                  | Definition                                                                                                                                                                                                                                                                                            | Code Reference                                                                                             |
| :------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- |
| **Platform** (`PlatformId`)           | A video/streaming service with first-class TubeSize support: `"youtube"`, `"twitch"`, or `"kick"`. Distinct from a general **Site**.                                                                                                                                                                  | [`src/lib/constants.ts`](src/lib/constants.ts), [`src/types/types.ts`](src/types/types.ts)                 |
| **Content Type** (`VideoContentType`) | Whether a media item has a fixed duration (`"vod"`) or is an ongoing broadcast (`"live"`). Unified across YouTube, Twitch, and Kick; YouTube VODs additionally carry an optional `isShorts` flag.                                                                                                     | [`src/types/types.ts`](src/types/types.ts), [`src/types/platforms.types.ts`](src/types/platforms.types.ts) |
| **Media Identifier** (`mediaId`)      | The platform-local identifier for a watchable item: 11-char ID on YouTube, numeric VOD ID or channel login on Twitch, UUID/slug or channel name on Kick.                                                                                                                                              | [`src/lib/platformUrl.ts`](src/lib/platformUrl.ts), [`src/lib/videoMetadata.ts`](src/lib/videoMetadata.ts) |
| **Video Key** (`VideoKey`)            | Branded globally unique composite key `<platform>:<mediaId>` (e.g. `youtube:dQw4w9WgXcQ`, `twitch:shroud`) constructed via `toVideoKey` and used to join `watchHistory` and `videoMetaData` in IndexedDB.                                                                                             | [`toVideoKey`](src/lib/platformUrl.ts), [`src/db.ts`](src/db.ts)                                           |
| **Video Metadata** (`VideoMetadata`)  | Cached descriptive record for a watched item (`type: PlatformId`, `title`, `channelName`, `channelUrl`, `thumbnailUrl`, optional `contentType` and `url`), lazily fetched via each platform module's metadata fetcher and persisted single-flight by `videoMetadata.ts` in IndexedDB `videoMetaData`. | [`src/db.ts`](src/db.ts), [`src/lib/videoMetadata.ts`](src/lib/videoMetadata.ts)                           |

## 2. Formats, Codecs & Size Estimation

| Term                                                  | Definition                                                                                                                                                                                                                                                                                                                                                                                                              | Code Reference                                                                                                                                               |
| :---------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Media Estimate** (`MediaEstimate`)                  | Normalized, platform-agnostic estimate payload (`VodMediaEstimate \| LiveMediaEstimate`, discriminated by `contentType: "vod" \| "live"`) returned by the single `estimateMedia` background RPC, carrying uniform `formats[]` (`VodMediaFormat[]` / `LiveMediaFormat[]`), header metadata, and an optional separate `audio` track.                                                                                      | [`src/types/platforms.types.ts`](src/types/platforms.types.ts), [`src/entrypoints/background/estimateMedia.ts`](src/entrypoints/background/estimateMedia.ts) |
| **Display Format** (`DisplayFormat`)                  | UI projection of a selectable quality tier produced by `projectEstimateFormats` (`kind: "vod" \| "live"`, `key`, `resolution`, `sizePerSecondBytes`, `sizeBytes` for VODs, optional `hideRate` for Shorts), with separate audio optionally folded in. Consumed by the Popup, Toaster, and Quality Menu Injector.                                                                                                        | [`src/types/platforms.types.ts`](src/types/platforms.types.ts), [`src/lib/mediaEstimate.ts`](src/lib/mediaEstimate.ts)                                       |
| **Quality Tier / Resolution**                         | Vertical pixel height identifying a selectable stream tier (e.g. `1080`, `720`). On YouTube, `getFormatHeight` parses `qualityLabel` (nominal height, e.g. `720` even on cropped aspect ratios) and falls back to `format.height ?? 0` when unparseable, whereas [`src/entrypoints/content/resolution.ts`](src/entrypoints/content/resolution.ts) reads physical `video.videoHeight` from the active `<video>` element. | [`getFormatHeight`](src/lib/youtube.ts), [`src/entrypoints/content/resolution.ts`](src/entrypoints/content/resolution.ts)                                    |
| **Itag** (`formatId`, `VideoItag`, `AudioItag`)       | YouTube's numeric identifier for a specific adaptive stream encoding (e.g. `251` Opus VOD audio, `140` AAC live audio, `399` 1080p AV1).                                                                                                                                                                                                                                                                                | [`src/lib/youtube.ts`](src/lib/youtube.ts), [`src/types/platforms.types.ts`](src/types/platforms.types.ts)                                                   |
| **Audio Stream Info** (`AudioStreamInfo`)             | Description of a separate audio track on DASH platforms such as YouTube (`251` for VOD, `140` for live). `MediaEstimate.formats` stores video-only sizes when `audio` is present, and `projectEstimateFormats` adds audio size/rate when `includeAudio` is enabled (default `true`).                                                                                                                                    | [`parseAudio`](src/lib/youtube.ts), [`projectEstimateFormats`](src/lib/mediaEstimate.ts)                                                                     |
| **Codec Support / AV1 Support** (`CodecSupportCache`) | Device-local check via `navigator.mediaCapabilities.decodingInfo` for power-efficient 4K AV1 decoding (cached 7 days in `local:codecSupport`). Controls whether YouTube estimates above `1080p` prefer `av01` or fall back to `vp9`/`avc`.                                                                                                                                                                              | [`src/lib/codecSupport.ts`](src/lib/codecSupport.ts), [`getPreferredCodecs`](src/lib/youtube.ts)                                                             |
| **Master M3U8 / Media Playlist**                      | HLS manifests used by Twitch and Kick. The Master M3U8 lists quality variants (`RESOLUTION`, `BANDWIDTH`); each variant points to a Media Playlist listing individual media segments.                                                                                                                                                                                                                                   | [`src/lib/hls.ts`](src/lib/hls.ts)                                                                                                                           |
| **HLS Segment Sampling**                              | Live-stream estimation method for Twitch and Kick: sends `Range: bytes=0-0` probes on up to 10 `"live"` segments to compute real bytes/sec from `Content-Range`, falling back to Master M3U8 `BANDWIDTH` if ads are detected or probes fail. Currently gated by `isFromPopup: true`.                                                                                                                                    | [`resolveHlsStreams`](src/lib/hls.ts)                                                                                                                        |
| **Media Cache**                                       | TTL-backed cache of `MediaEstimate` in `chrome.storage.local` keyed as `local:<platform>:<id>`. Validates one uniform `MediaEstimate` shape without platform switches. VODs use the user's `cacheTTL` (default 3 days); YouTube live uses `LIVE_CACHE_TTL` (5 min); Twitch/Kick live streams are not cached. Entries with empty or zero-size formats are skipped, and legacy cache entries are evicted on read.         | [`src/lib/mediaCache.ts`](src/lib/mediaCache.ts)                                                                                                             |

## 3. Usage Tracking & Attribution

| Term                                   | Definition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Code Reference                                                                                                                                                                                                                                         |
| :------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Origin** (`Origin`)                  | Branded scheme + host + port of the tab (`toOrigin(tab.url)`, e.g. `https://www.youtube.com`). Used as the raw map key inside `SiteUsage.usage` in IndexedDB.                                                                                                                                                                                                                                                                                                                                           | [`src/entrypoints/background/usageTracker.ts`](src/entrypoints/background/usageTracker.ts), [`src/db.ts`](src/db.ts)                                                                                                                                   |
| **Site Key** (`SiteKey`)               | Branded normalized aggregation key for reporting: registrable domain (`example.com`) for most origins, full hostname without `www.` for Google subdomains (`drive.google.com`), or the raw origin when no registrable domain exists.                                                                                                                                                                                                                                                                    | [`getSiteKey`](src/lib/domain.ts), [`sumBySite`](src/lib/domain.ts)                                                                                                                                                                                    |
| **Site Label**                         | Human-readable display name for a site key (e.g. `"Google Drive"`, `"Gmail"`, `"Youtube"`).                                                                                                                                                                                                                                                                                                                                                                                                             | [`getSiteLabel`](src/lib/domain.ts)                                                                                                                                                                                                                    |
| **Site Usage** (`SiteUsage`)           | Daily IndexedDB record (`siteUsage` table, keyed by `day: DateKey`) mapping `origin -> bytes`.                                                                                                                                                                                                                                                                                                                                                                                                          | [`src/db.ts`](src/db.ts)                                                                                                                                                                                                                               |
| **Watch History** (`WatchHistory`)     | Daily IndexedDB record (`watchHistory` table, keyed by `day: DateKey`) mapping `videoKey -> bytes` for traffic observed on supported platform watch pages.                                                                                                                                                                                                                                                                                                                                              | [`src/db.ts`](src/db.ts)                                                                                                                                                                                                                               |
| **Dual-Path Usage Accounting**         | Complementary byte-counting split that avoids double-counting: (1) **Background `webRequest.onCompleted`** counts responses with a finite positive `Content-Length` header; (2) **Page-World Observer** (`PageUsageObserver` in `src/lib/pageUsageObserver.ts`, mounted by `genericObserver.content.ts`) patches `fetch`, `XMLHttpRequest`, and classic `blob:` `Worker`s with one `hasPositiveContentLength` skip rule to count streamed/chunked responses without a finite positive `Content-Length`. | [`src/entrypoints/background/usageTracker.ts`](src/entrypoints/background/usageTracker.ts), [`src/lib/pageUsageObserver.ts`](src/lib/pageUsageObserver.ts), [`src/entrypoints/genericObserver.content.ts`](src/entrypoints/genericObserver.content.ts) |
| **Usage Bridge**                       | Lightweight `ISOLATED`-world content script on `<all_urls>` with zero platform URL imports that validates and relays bytes-only `TUBESIZE_SITE_USAGE` window `CustomEvent`s (synchronous, so a closing tab's final flush is not lost) from the `MAIN`-world observer to the background `addUsage` handler.                                                                                                                                                                                              | [`src/entrypoints/usageBridge.content.ts`](src/entrypoints/usageBridge.content.ts)                                                                                                                                                                     |
| **Usage Ingestion** (`UsageIngestion`) | Unified background write module fed by both `webRequest.onCompleted` and `UsageBridge`, deriving `Origin`, `WatchHistory`, and single-flight `VideoMetadata` solely from trusted browser tab and frame URLs (`tab.url`, `sender.tab.url`, `sender.url`) with two-phase IndexedDB flushes, partial-failure rollback, and `UsageBadge` refresh.                                                                                                                                                           | [`src/entrypoints/background/usageIngestion.ts`](src/entrypoints/background/usageIngestion.ts)                                                                                                                                                         |
| **Date Key** (`DateKey`)               | Branded, boundary-validated local-timezone calendar date string formatted `YYYY-MM-DD`. Primary key for `siteUsage`, `watchHistory`, and `toasterSuppressedDate`.                                                                                                                                                                                                                                                                                                                                       | [`src/types/types.ts`](src/types/types.ts), [`src/lib/dateUtils.ts`](src/lib/dateUtils.ts)                                                                                                                                                             |
| **Usage Range** (`UsageRange`)         | Named rolling window: `"today"` (1 day), `"week"` (7 days), `"month"` (30 days), or `"lifetime"` (all stored days).                                                                                                                                                                                                                                                                                                                                                                                     | [`src/lib/constants.ts`](src/lib/constants.ts), [`getScopedSiteUsage`](src/lib/usage.ts)                                                                                                                                                               |
| **Usage Scope** (`UsageScope`)         | Discriminated union selecting either a single day (`{ type: "date", date }`) or a rolling window (`{ type: "range", range }`) for Dashboard queries.                                                                                                                                                                                                                                                                                                                                                    | [`src/types/types.ts`](src/types/types.ts), [`src/pages/dashboard/scope/scopePage.tsx`](src/pages/dashboard/scope/scopePage.tsx)                                                                                                                       |

## 4. Architecture, Surfaces & Settings

| Term                                           | Definition                                                                                                                                                                                                                                                                                                                                                                                                         | Code Reference                                                                                                                                                                                                                                           |
| :--------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Platform Descriptor** (`PlatformDescriptor`) | Pure, shared descriptor per platform in `src/lib/platformUrl.ts` owning supported hosts (and derived `PLATFORM_MATCH_PATTERNS`), canonical display name (`getPlatformDisplayName`), URL parsing (`parsePlatformUrl`), and canonical watch URL construction (`buildPlatformVideoUrl`).                                                                                                                              | [`src/lib/platformUrl.ts`](src/lib/platformUrl.ts), [`src/entrypoints/content/index.ts`](src/entrypoints/content/index.ts)                                                                                                                               |
| **Media Estimation Seam** (`estimateMedia`)    | Single background RPC (`estimateMedia`) backed by a `PlatformId` estimator registry (`src/entrypoints/background/estimateMedia.ts`) dispatching via `parsePlatformUrl`. Callers (`Popup`, `ContentSession`) use `requestMediaEstimate`, `projectEstimateFormats`, and `formatEstimateHeader` in `src/lib/mediaEstimate.ts` with no per-platform switches.                                                          | [`src/entrypoints/background/estimateMedia.ts`](src/entrypoints/background/estimateMedia.ts), [`src/lib/mediaEstimate.ts`](src/lib/mediaEstimate.ts), [`src/messaging.ts`](src/messaging.ts)                                                             |
| **Content Session** (`ContentSession`)         | Per-navigation content-script lifecycle created by `createContentSession` and backed by one `AbortController`. Driven by `wxt:locationchange` across all supported SPA platforms, loads `MediaEstimate` via `requestMediaEstimate`, projects `DisplayFormat[]`, cancels prior observers/listeners on navigation, runs optional per-platform content hooks (`CONTENT_PLATFORM_HOOKS`), and coordinates the Toaster. | [`src/entrypoints/content/contentSession.ts`](src/entrypoints/content/contentSession.ts), [`src/entrypoints/content/platformHooks.ts`](src/entrypoints/content/platformHooks.ts), [`src/entrypoints/content/index.ts`](src/entrypoints/content/index.ts) |
| **Quality Menu Injector**                      | YouTube-only `MutationObserver` that injects estimated primary size badges into YouTube's native `.ytp-quality-menu` panel.                                                                                                                                                                                                                                                                                        | [`src/entrypoints/content/qualityMenuInjector.ts`](src/entrypoints/content/qualityMenuInjector.ts)                                                                                                                                                       |
| **Toaster** _(Bandwidth Warning Toast)_        | Vanilla-DOM in-page warning overlay rendered inside an open Shadow DOM on `#TubeSize-Toast-Host` (with encapsulated `?inline` styles from `src/styles/toast.css`) shown when the active video's resolution exceeds `toasterThreshold` (MB/hour). Can be dismissed or suppressed for the current local day (`toasterSuppressedDate`).                                                                               | [`src/entrypoints/content/toaster.ts`](src/entrypoints/content/toaster.ts), [`src/entrypoints/content/contentSession.ts`](src/entrypoints/content/contentSession.ts)                                                                                     |
| **Usage Badge**                                | Extension toolbar action badge showing today's cumulative all-sites usage in compact SI form (e.g. `450M`, `1.2G`), cleared when `0 B`. Refreshed on usage flush, browser startup, extension install/update, and local midnight rollover via `chrome.alarms`.                                                                                                                                                      | [`src/badge.ts`](src/badge.ts), [`src/entrypoints/background/badgeRollover.ts`](src/entrypoints/background/badgeRollover.ts), [`formatBadge`](src/lib/format.ts)                                                                                         |
| **Settings** (`SettingsMap`)                   | User preferences persisted in `chrome.storage.sync`: `toasterEnabled`, `toasterThreshold` (MB/hour, default `500`), `cacheTTL` (seconds, default 3 days), `advancedView` (show itags/codecs/fps), and `includeAudio`. `language` is also persisted in `chrome.storage.sync` and managed separately by [`src/i18n/language.ts`](src/i18n/language.ts).                                                              | [`src/lib/settings.ts`](src/lib/settings.ts), [`src/i18n/language.ts`](src/i18n/language.ts)                                                                                                                                                             |
